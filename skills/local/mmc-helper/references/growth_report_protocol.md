# 赛后成长报告协议

> 用途：每次比赛收尾写成长报告（**每次必写**），回写 `user_profile.md`，供下次 Phase 0 复用。报告骨架见 `templates/growth_report_template.md`。

## 1. 内容
- 本次做得好 / 待改进 / 下次具体怎么提升（教师式复盘）。

## 2. 输出
- `06_汇总交付/赛后成长报告.md`。
- 结论回写 `_mmc_internal/user_profile.md`。

## 3. 闭环
- 下次 Phase 0 读取更新后的 `user_profile.md`，作为参赛介绍 + 自我精进指引。

## 回写规则

- 回写 `user_profile.md` 的"经验"与"偏好"字段；
- 把新发现的通用缺陷补进 `references/known_pitfalls.md`；
- 把新提炼的写作范式补进 `references/style_patterns.md`；
- **报告只写事实与可复用的结论**，不写情绪化评价。
