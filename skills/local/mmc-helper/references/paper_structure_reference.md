# 优秀建模论文结构参考（论文手核对用）

> 用途：帮助论文手对齐**优秀/获奖数学建模论文**的结构与写法，写作**详实、讲清论证链条、图表说明到位**，避免过度简洁或"不够权威"。各竞赛对格式要求不同，以 `references/competition_profiles.md` 为准，本文件提供**通用高分骨架与要点**。

## 一、标准结构（获奖作品常见骨架）
1. **摘要**（最后写，一页内讲清：问题→做了什么→结果→结论）
2. **问题重述**（凝练，不是抄题）
3. **问题分析**（逐问讲思路：这属于什么模型、可用什么算法、方向、难点）
4. **模型假设与符号说明**（假设明确、可检验；符号统一列成表）
5. **模型的建立与求解**（每问一个模型：变量/参数/约束/目标/方程 + 为什么这么建模 + 求解算法与步骤）
6. **结果分析**（结果展示 + **解释**：说明什么、可信度、与预期对比）
7. **灵敏度/稳健性分析**（相关小问必做：参数扰动，结论是否稳）
8. **模型的评价与推广**（优点/局限/推广，诚实）
9. **结论**（回答题目要求，不引入新结果）
10. **参考文献**（规范、与正文一一对应）
11. **附录**（代码/数据表/中间推导，按赛题要求）

> **写前先对齐模板层级**：各竞赛模板层级差异大，动笔前必须按**官方赛题模板**定骨架（国赛：模型假设/符号说明**分节**，问题X 嵌在"模型的建立与求解"下，其下再分"模型的建立/模型的求解/结果分析"——骨架见 `templates/paper_skeleton_template.tex`；美赛：Summary → Introduction → …）。不要把每个小问做成顶层节。版式规则全文见 `templates/paper_format_rules.md`。

## 二、每节的"够不够好"要点

| 节 | 获奖作品常见加分写法 | 常见"简陋"表现 |
| --- | --- | --- |
| 摘要 | 四段式、有量化结果、逻辑清晰 | 空泛、无结果、像简介 |
| 问题重述 | 凝练+说清"要交付什么" | 大段抄题 |
| 问题分析 | 逐问讲"是什么模型/算法/难点" | 没分析直接上模型 |
| 假设 | 明确可检验、说明不成立的后果 | 一句草率略过 |
| 建模 | 有"为什么这样建模"的推理 + 公式每个符号都交代 | 只罗列公式 |
| 求解 | 算法步骤、复杂度、为何能解 | 只给结果代码 |
| 结果分析 | **结果+解释+可信度**，图能自解释 | 只放图不做解释 |
| 灵敏度/稳健 | 参数扰动、结论稳定性 | 缺（扣分） |
| 评价与推广 | 诚实写局限 | 只夸 |
| 引用 | `\cite{}` ↔ `.bib` 一一对应 | 乱序/缺项 |

## 三、高分要点（写作原则）
1. **有依据**：每个结论都有素材支撑，推断用限定语（证据分级）。
2. **讲清楚论证链条**：不只是"我用了 X"，而是"我为什么用 X、它解决了什么、结果如何支撑"。
3. **详实不空泛**：宁可写具体的一步，也不写一句正确的空话。
4. **图/表要自解释**：标题、坐标轴、单位、图例齐全；正文对每个图/表都有说明与解读。
5. **结构完整、前后一致**：结论必须回答题目要求；模型假设贯穿求解；结果与摘要一致。
6. **克制"官方腔"但保持学术**：清楚、直接、有逻辑，不堆套话，也不口语化。

## 四、常见扣分点（务必避免）
- 摘要空泛 / 无结果 / 引入正文没有的结论。
- 题目要求没逐问回答 / 漏小问。
- 模型假设与求解不一致（自相矛盾）。
- 结果只给图/表不给解释；或图坐标轴/单位/图例缺失。
- 缺**灵敏度/稳健性**分析（相关题）。
- 引用不真、编号乱、正文引用与 `.bib` 对不上。
- **把推断写成实测**（证据分级违规）。
- 论文过长/过短、格式不符赛题要求。
- **结构未对齐官方模板**：每问做成顶层节、模型假设/符号说明不合模板分节、摘要页版式不合（题目未居中/字号大/混入"本文亮点"）。
- **版式不合规**：非三线表、符号表一行两排、题注塞太多、彩色填充框 / `\boxed` / 彩色链接、小标题过细且无实结果、超行宽——**能编译 ≠ 排版合格**（规则与自检见 `templates/paper_format_rules.md`）。

## 五、复杂图（流程图/结构图）交用户协助
- 智能体不易绘制较复杂图形（流程图、模型结构图等）→ **请用户协助制作**。
- 智能体提供：内容要点 / 文字流程 / ASCII 草图 / 可复制到 draw.io、Visio 等的节点关系描述；由用户渲染成图，再放回论文。

## 六、获奖论文学习库
- **实体库**：`paper-library/`——库内 20 篇获奖论文的**逐篇笔记索引**见 `paper-library/README.md`；其中**同题的三篇深读**在 `paper-library/deep-reads/`。
- **读法**：**立项时读一次**（建立整体印象），**正文动笔前再读一次**（把写法落到具体章节）；第二次不可省。
- **边界**：只借**结构与写法**，不搬方法与数值结论。
- **启动时主动询问用户**"是否有针对本赛题的目标优秀论文/获奖作品"，有则聚焦学习其结构与表达，从而更好对齐（优先于内置库）。
- **只借写法，不搬内容**：优秀论文/获奖作品仅作**结构、表达、图表写法**的示范，其建模内容/结论不得混入本题模型（防止"优秀论文≠本题内容"导致跑题）。
