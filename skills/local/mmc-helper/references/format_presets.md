# 格式预设与排版自检（论文）

> 用途：给论文的**格式与版式**做预设与自检，避免"结构没对齐模板、表格撑破页宽、公式超边距"等排版问题。
> **关键：格式在写作前就要清楚（写稿即遵守），不能等定稿才返工**——论文手动笔前先读 `templates/paper_format_rules.md`（格式与版式规则·写作前必读），再按本文件取格式预设值。
> **优先级**：赛题通知/官方说明 > 用户提供的**优秀论文模板** > 本文件内置默认（常用的参考值）。
> 关联：`templates/paper_writing_guide.md`（写作导引·主件）、`templates/paper_format_rules.md`（版式规则全文）、`templates/paper_skeleton_template.tex`（对齐模板的骨架）、`templates/submission_checklist_template.md`（收尾清单）、`references/competition_profiles.md`（竞赛画像）。

## 一、内置默认格式预设（常用参考值，以官方/用户模板为准）

### 国赛（CN_CUMCM · 常见）
| 项 | 常用参考值 |
| --- | --- |
| 页边距 | 上 2.5cm、下 2.5cm、左 3cm、右 2.5cm |
| 正文 | 中文宋体（或默认）、小四或五号、1.5 倍行距 |
| 标题 | 一级 黑体/加粗、居中；分级编号清晰 |
| 摘要 | 单独一页：题目居中大号粗体、"摘要"居中、正文小字号（如五号）紧凑；含关键词 |
| 图表 | 图/表编号连续、有标题；单位、坐标轴、图例齐全 |
| 参考文献 | 规范（如 GB/T 7714 / 国赛惯例），正文 `\cite{}` 对应 |
| 页码/页眉 | 常要求；遵守官方 |
| 分节 | 摘要→问题重述→问题分析→模型假设→符号说明→模型的建立与求解（问题X）→模型的分析与检验→模型的评价·改进·推广→参考文献→附录 |

### 美赛（US_MCM/ICM · 常见）
| 项 | 常用参考值 |
| --- | --- |
| 摘要页 | 单页、含关键词（Summary / Keywords） |
| 结构 | Summary → Introduction → Assumptions → Notation → Models → Results → Sensitivity/Robustness → Conclusion → References |
| 语言 | 英文；清晰、克制、学术 |
| 图表 | 编号连续、标题与单位齐全；Team # 标注 |
| 引用 | 规范；正文对应 |

> 说明：以上为**常见参考值**，**务必以当年赛题通知/官方说明为准**（Phase 0 已提取），并以用户提供的**优秀论文模板**为准覆盖。

## 二、用户优秀论文模板提取（当用户提供了获奖/优秀论文时）

1. **读取用户论文**，提取其**格式约定**：字体、字号、行距、页边距、分节顺序、标题样式、图/表编号与标题体例、参考文献格式、摘要写法、字数/页数。
2. 生成一份"**用户模板**"要点（存 `01_题目剖析/` 或该用户档案），**覆盖/补充**内置默认。
3. 在**写作前**把该层级/体例展示给用户确认；最终产出前**逐项核对**是否与该模板一致。

> 注意：优秀论文/获奖作品**只借结构与写法**作示范，不搬其内容/结论到本题模型（防跑题内容混入）。

## 三、写作前对齐（论文手动笔前必做）

1. 读 `templates/paper_format_rules.md`（版式规则全文），明确：模板层级、三线表单对行、题注一行主标题、长公式分行、小标题精简有实结果、无彩色框/`\boxed`/彩色链接、无断点长串防溢出。
2. 打开 `templates/paper_skeleton_template.tex`，按**官方赛题模板**核对并定下正文标题层级，**不把每个小问做成顶层节**。
3. 有官方模板/优秀论文时先做 §二 提取并展示确认。

## 四、排版自检清单（写稿后/收尾必做）

> 本节是**速查汇总**；逐条细则与判定口径以 `templates/paper_format_rules.md` §7（写稿即跑）与 §8（收尾渲染终检）为准。

**结构 / 层级**
- [ ] 章节层级对齐官方模板（问题X嵌在"模型的建立与求解"下，其下"模型的建立/模型的求解/结果分析"）；无自造顶层节
- [ ] 摘要页版式：题目居中（大号粗体）、"摘要"居中、正文小字号紧凑；无"本文亮点"等非标准内容

**表格**
- [ ] 一律三线表（booktabs，无竖线）
- [ ] 符号说明等对照表每行一对（符号|含义），不一行放两排
- [ ] 内容多已精简/固定列宽/小字，收敛页宽内（宁可拆两表不撑破页宽）

**公式 / 溢出**
- [ ] 长公式 / 多 `cases` 已分行堆叠（`align`/`aligned`/`array`），无超行宽
- [ ] 无"行内无断点超长串"（区间、URL、长小数串、大分式）→ 已改表格/分行

**图表**
- [ ] 题注 = 一行主标题；补充（坐标轴/读法/来源）另起一行小字
- [ ] 无彩色填充框 / `\boxed{}` / 彩色 hyperref 链接（用 `hidelinks`）
- [ ] 图坐标轴/单位/图例齐全；正文对每个图/表紧跟解读（不单开"结果解读"小标题）

**编译 / 渲染**
- [ ] 编译无 `Overfull \hbox`、无缺字符、无未定义引用
- [ ] **渲染抽查关键页**（摘要页、图表页、表格页）：超行宽/表格撑破页宽/题注折行难看/图溢出页边
- [ ] 摘要与结论中的数值与正文一致

> 版式规则的"逐节自检"（写作中）与"收尾渲染终检"（Phase 3）细化条目见 `templates/paper_format_rules.md` §7 / §8。
