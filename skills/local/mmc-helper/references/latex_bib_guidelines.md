# LaTeX / 引用库管理与核对

> **适用范围**：**选用 LaTeX 排版时**参考本文件。若使用 Word、Markdown 等其它工具，
> 通用要求（章节层级、图表体例、引用核对、渲染抽查）见 `references/tool_and_env_guide.md`
> §3.2–§3.3（与排版工具无关）。
>
> 用途：管理引用并核对一致性。

## 1. 基本约定
- 每子问题一份 `refs.bib`；正文用 `\cite{}`。
- 支持 `biblatex` / `natbib` 切换。
- 图统一放 `04_代码实现/` 下，`.tex` 用 `\includegraphics{}` 引用。

## 2. 收尾核对
- 正文引用 ↔ `.bib` 条目**一一对应**（无多余、无缺失）。
- 每条引用已验证（接三查两证·真实性凭证）。

## 工程组织

- 一章一个文件，主文件只做 `\input` 与顺序编排；这样可单章预览、可并行编辑、diff 干净；
- 导言区单独成文件，便于全篇与单章预览共用同一套设置；
- 图片放在独立目录，按"问题号_用途"命名。

## 引用库管理

- **一个条目一个键**，键名用"作者+年份+主题词"，保证可读且唯一；
- **每条都必须带可验证标识**（DOI 或稳定链接）；
- **未核实的条目标记状态，绝不进入 `\cite{}`**；
- 引用键必须**逐个核对**，不得凭语义猜测；
- 引用编号按**正文出现顺序**（用 `unsrt` 类样式）。

## 常见问题


| 现象 | 原因 | 处理 |
|---|---|---|
| 引用角标在单章预览与全文中编号不同 | 预览只编译本章，重新排序了 | 预览模式直接指向全文已生成的引用库 |
| 满篇未定义引用 | 交叉引用未收敛 | 多编译一次；仍有则检查标签是否被删 |
| 引用指向错误位置 | 同名标签被定义两次 | 全库搜标签名去重 |
| 中文条目乱码 | 编码或字体 | 统一 UTF-8；字体显式指定 |
