# 用户画像 schema

> 用途：跨比赛累积的用户画像（`_mmc_internal/user_profile.md`），记录建模 / 写作 / 编程的强弱项倾向，
> 供 Phase 0 个性化与赛后成长闭环使用。

## 1. 建议字段

| 字段 | 说明 |
|---|---|
| `background` | 专业与年级、擅长的方向（建模 / 编程 / 写作）、参赛经历与成绩 |
| `tools` | 常用语言与求解器、环境、是否熟悉 LaTeX |
| `style` | 偏好的表达风格、人称习惯、格式讲究程度 |
| `workflow` | 偏好的协作节奏（逐步确认 / 阶段确认）、是否要求先给草稿 |
| `modeling` | 建模倾向：偏爱的模型复杂度（简单 / 中等 / 进阶）、常用方法族、易犯问题（如模型过于简单） |
| `writing` | 写作倾向：风格与易犯问题 |
| `coding` | 编程倾向：熟练度、**分工偏好**（智能体主导 / 用户主导 / 混合） |
| `history` | 参加过的赛事与成绩、此前复盘结论 |
| `focus` | 本次赛事特别关注的点 |

## 2. 用途

- 本次 Phase 0 读取 → 生成**本赛个性化关注点**，注入对应阶段；
- 赛后成长报告回写更新（见 `references/growth_report_protocol.md`）。

## 3. 维护方式

- **立项时读**：读取历史画像，确认本次是否沿用；
- **赛中共更新**：用户提出的新偏好随到随记；
- **收尾时回写**：把成长报告的结论回写进画像；
- **软引导而非硬约束**：画像是默认值，用户当场的明确要求优先。
