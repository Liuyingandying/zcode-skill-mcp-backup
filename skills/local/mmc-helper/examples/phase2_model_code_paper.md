## 建模手：模型规格书（节选）

**基本**：小问 1 采用**熵权法 + TOPSIS**，属**评价类**。依据方法推荐矩阵·评价类（文献贴合度高，见文献矩阵 Hits: 高）。为什么用这个：客观赋权避免主观、贴近度排序直观、实现快、好解释，适合作为论文的"评价模块"并支撑后文。

**假设**：① 各区域指标方向已按"效益/成本"核校；② 极端值经预处理后不主导权重；③ 样本量足够（≥ 点位量）。

**数学形式**：构造决策矩阵 → 熵权法求权重 → 加权向量归一化 → 计算各区域到正/负理想解距离 → 贴近度排序。关键式（示意）：
`w_j = (1 - E_j) / Σ(1 - E_k)`，贴近度 `C_i = D_i^- / (D_i^+ + D_i^-)`。

**参数定义**（完整，节选）：
| 参数 | 量纲 | 取值/范围 | 如何确定 |
| --- | --- | --- | --- |
| 指标方向 | 0/1 | 效益型=1，成本型=0 | 按指标物理含义 |
| 归一化 | 无量纲 | [0,1] | 按方向分式归一/倒极差 |

**求解算法**：按上述矩阵运算（`numpy`，可直接向量化），复杂度 O(n·m)，规模几乎即时。

**预期输出**：各区域贴近度 `C_i ∈ [0,1]`、质量排序、主要短板指标归因。

**达标判据**：① 指标方向核对一致 ✅；② 权重非极端（无单一权重>0.5即可接受，需说明）；③ 排序与直觉/数据基本一致（供用户核对）。

**反驳清单**：若指标高相关或存在极端值主导 → 排序失真；退路：PCA 降维 + TOPSIS，或加 AHP 主观权重。已与用户说明。

**用户最终确定**：用户选定熵权+TOPSIS；我的专业意见与之相符（好解释、稳）。

## 角色职责边界（示例体现）
- 建模手：只给出规格书与选型，未写正式代码。
- 编程手：只跑/调/回环，未擅自改模型（回环是"提出异议+建议"，由建模手定夺）。
- 论文手：基于素材写结果，未改动模型/代码；把"推断"用限定语，未写成"实测"。
- 审核手：**只质疑、不生产**；T1 拦在编码前、T2 拦在写作前，未过审的内容没有流到下游。
