# examples/ — 分阶段运转示例

> **示例仅演示 skill 的运转方式**：其中的题目、数据与结论**均为虚构**，不代表任何真实竞赛。
> **示例不绑定语言与工具**——用什么语言、什么求解器、什么排版工具，由用户在 Phase 0 确定。

## 端到端与分阶段示例

| 文件 | 演示内容 |
|---|---|
| `end_to_end_dialog.md` | **端到端人机协同演示**：从预准备到收尾的完整对话形态，每一步都体现「完成 → 展示 → 留窗口 → 用户意见 → 执行」，并对比两种工作模式 |
| `phase0_startup.md` | **立项**：工作模式与分工模式确认、资料收集、竞赛 Profile、用户画像、运行模式 |
| `phase1_analysis.md` | **剖析与文献**：问题重述 → 问题分析 → 候选方向（≥2 方法族 + tradeoff + 反驳清单）→ 三查两证 → 文献矩阵 |
| `phase2_model_code_paper.md` | **分角色攻坚**：建模手 → 审核手（T1）→ 编程手 → 审核手（T2）→ 论文手；含一次"异常 → 回环 → 重开方向"的完整处理 |
| `phase3_wrapup.md` | **收尾**：结构梳理 / 摘要 / 综述检查 / AI 使用说明 / 提交清单 / 成长报告 |

## 使用提示

- 示例覆盖**评价 / 预测 / 优化**三类问题，展示四阶段如何连续运转；
- 看示例时关注**动作与留痕**（每步展示什么、留什么痕、闸门怎么设），而不是示例里的具体题目；
- 方法与工具的选择见 `references/method_recommendation_matrix.md`；
  环境的适配方式见 `references/tool_and_env_guide.md`。
