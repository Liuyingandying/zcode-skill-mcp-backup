## v2.0.3 — 首次公开发布

首个公开发布版本。

- **四阶段状态机**：立项 → 题目剖析与文献集结 → 分角色攻坚 → 汇总收尾，阶段之间有闸门。
- **四角色协作**：建模手 / 编程手 / 论文手 / **审核手**（只质疑不生产，T1 拦在编码前、T2 拦在写作前）。
- **协议层**：强锚定、启动自检、交接与留痕、审核、批量意见处理。
- **三查两证**：查真实、查贴合、查思路 + 证据分级、可行性试点验证。
- **写作支撑**：写作范式库、写作契约（增量台账）、**已知坑清单**（18 条，每条附"如何检出"）、获奖论文学习库。
- **工具与环境无关**：语言 / 求解器 / 编辑器 / 排版工具由用户在 Phase 0 确定，缺能力时走降级路径。

能力范围与安装方式见 `SKILL.md` 与 `README.md`。
