# 角色卡索引与「角色 × 协议」矩阵

## 一、角色一览

| 角色 | 卡片 | 一句话职责 | 输出契约 |
|---|---|---|---|
| 立项助手 | `startup_agent.md` | 确定模式、建工作区、收集资料、启动自检 | `state.json`、画像、留痕骨架 |
| 建模手 | `modeler_agent.md` | 选最贴合的模型并讲清楚 | **模型规格书**（可读性达标） |
| **审核手** | `auditor_agent.md` | **只质疑、不生产** | 审核意见（含交叉审查链） |
| 编程手 | `coder_agent.md` | 让模型可运行、结果达标 | 代码 + 结果 + 图 + **素材登记** |
| 论文手 | `writer_agent.md` | 写出**用户无需重写**的论文 | 论文章节 + 复读清单 + 编译指标 |
| 收尾助手 | `wrapup_agent.md` | 汇总、检查、交付 | 提交清单、成长报告、清理报告 |

## 二、角色 × 协议矩阵（**必查**）

| 协议 \ 角色 | 立项 | 建模手 | 审核手 | 编程手 | 论文手 | 收尾 |
|---|:--:|:--:|:--:|:--:|:--:|:--:|
| `anchoring` 强锚定 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| `startup_verify` 启动自检 | ✅ | | | | | ✅ |
| `audit_protocol` 审核 | | 配合 | ✅ | 配合 | | ✅ |
| `handoff_protocol` 交接与留痕 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| `batch_feedback_protocol` 批量意见 | ✅ | ✅ | | ✅ | ✅ | ✅ |
| `quality_control_protocol` 三查两证 | ✅ | ✅ | | | ✅ | ✅ |

**说明**：
- **强锚定与留痕协议**：**全部角色、全程适用**；
- **审核协议**：审核手主责，建模手/编程手负责**应答**；
- **批量意见协议**：凡接收用户多条目反馈的角色均适用；
- **三查两证**：查文献与资料真实性，主要在剖析、建模、写作阶段使用。

## 三、交接链

```
立项 ──▶ 剖析/文献 ──▶ 建模手 ──[T1 审核]──▶ 编程手 ──[T2 审核]──▶ 论文手 ──▶ 收尾
                          ▲                      │
                          └────── 回环（模型需修正）──────┘
```

**交接靠"工件"而非对话记忆**：每次交接必须有明确的产出物与验收判据；
未过审的内容**不得进入下一环节**。

---

## 四、通用交互协议（所有角色）

每一步：**完成 → 展示（做了什么／结果／依据）→ 留窗口给用户 → 用户意见 → 执行**。
按工作模式（A 仅协助 / B 全权代理）调整"是否逐键入"。
