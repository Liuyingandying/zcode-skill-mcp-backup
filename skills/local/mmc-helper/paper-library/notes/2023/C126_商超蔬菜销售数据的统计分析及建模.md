- **一句话定位**：**贝叶斯统计主线**的 C 题解法——针对销量非正态、零膨胀、含大量 0 的数据，Shapiro-Wilks 检验证伪正态后以"同期平均法"压缩三年数据，用 WinBUGS+MCMC（30000 迭代/燃烧 3000）建 Bayesian 销量与补货量模型答 Q1；VAR(2) 多变量时序预测（Q2/Q3 底座），Lingo 优化求解"成本利润率→定价+补货量"。
- **结构提纲**：顶层仅五章+附录：一、问题重述（叙述式列问题 1–4）→ 二、模型假设（**仅 2 条**）→ 三、符号说明 → **四、模型建立与求解（所有问题嵌此章内）**→ 五、参考文献 → 附录。章下 4.1 问题一 / 4.2 蔬菜销量的 Bayesian 模型 / 4.3 各类别品种销量指标的 Bayesian 模型 / 4.4 问题二 / 4.5 优化模型求解成本利润率 / 4.6 问题三求解 / 4.7 问题四（建议），小节 4.x.y 编号。**即"问题 X 嵌在模型建立与求解下"而非每问一层**；顶层**缺"问题分析"与"模型评价"章**。
