# 学习笔记：基于遗传算法的最优种植策略（2024C · 国奖优秀论文）

**题目（年份·题号·奖项语境）**：2024 年全国大学生数学建模竞赛 C 题获奖优秀论文《基于遗传算法的最优种植策略》（2024C · C234）（45 页，正文至约 p.25）

- **一句话定位**：从"数据补全与指标整理"起步，以某年某地块某作物种植面积为决策变量建立总利润单目标优化模型，用带早熟判断的启发式遗传算法求解，并通过"不确定因子（均匀分布）+ 干旱/寒潮灾害因子"与"替代/互补集合+供需关系相关性"逐问修正的论文。
- **结构提纲**：**问题 X 嵌在"模型的建立与求解"之下**（6.1/6.2/6.3）。一、问题背景与重述（1.1 背景 / 1.2 重述）→ 二、问题分析（2.1–2.3 逐问分析 + 2.4 总思路图）→ 三、模型假设（4 条）→ 四、符号说明 → 五、数据处理与分析（5.1 数据补全〔智慧大棚第一季数据用普通大棚补〕/ 5.2 农作物对耕地类型需求 / 5.3 各耕地季次对应季节 / 5.4 亩产量、成本与售价指标表 / 5.5 2023 预期销量与单位利润）→ 六、模型的建立与求解：6.1 问题一（6.1.1 决策变量 / 6.1.2 利润最大化目标〔含滞销利润因子〕/ 6.1.3 约束条件 / 6.1.4 模型汇总 / 6.1.5 遗传算法求解与分析〔编码、适应度、早熟判断、进化曲线与合理性自检〕）、6.2 问题二（6.2.1 不确定性〔均匀分布因子〕/ 6.2.2 潜在种植风险〔干旱因子、寒潮因子〕/ 6.2.3 模型修正 / 6.2.4 求解〔方案 1/2/3 + 利润波动指标选案〕）、6.3 问题三（6.3.1 替代与互补集合 / 6.3.2 成本-价格-预期销量相关性〔供需关系〕/ 6.3.3 总模型 / 6.3.4 求解与对比）→ 七、模型的评价、改进与推广（7.1–7.4）→ 八、参考文献 → 附录 1–15。
- **摘要写法**：约 900–1100 字（按页字符粗估），问题一/二/三各一段并量化（Q1 滞销 29,276,719.5 元、折价 42,837,286.75 元；Q2 抗风险最优方案 38,732,308.4505 元；Q3 模拟数据 37,304,570.2468 元，并解释较 Q2 下降原因），末段点明有优缺点总结与改进；无"本文亮点"段；关键词 4 个（其中"均分分布"疑为"均匀分布"笔误或提取噪声，正文他处写作均匀分布）。
- **问题 X 的逐问组织**：问题一内部最细（决策变量→目标→约束→模型汇总→求解与分析五级）；问题二/三相对压缩，均在上一问模型上"说明新增要素→修正模型→求解→对比"；每问结果后接"方案合理吗"的自检与原因解释。
- **图表体例**：图 1–17 连续编号、表 1–3 连续编号，题注多与编号同行（"图 13 方案1 号的进化曲线"、"表 2 季次与农作物的亩产量、种植成本与销售价格（部分）"）；符号说明为三栏表（符号/说明/单位）一行一符号，且把 A/B/C/D/E/F 地块集合、粮食/蔬菜/食用菌/豆类作物集合也列作符号；是否三线表文本层不可判定。
- **写作/表达特色**：① 建模前有完整"数据处理与分析"章：先补全缺失数据、再建"耕地-作物适配、季次-季节、亩产-成本-售价"等中间表，流程示范性强；② 遗传算法落地参数具体（种群 100、进化 200 代、变异率 10%、最优个体占比>10% 判定早熟并插入新基因、父子合并淘汰），配"验证可行性流程图"；③ 用"极端基准情景"做 sanity check（只在 2025/2027/2029 种高利润作物、其余年份只补豆类，估算约 1788 万元），证明 GA 方案 2927 万元数量级合理；④ 把"潜在种植风险"具体化为华北干旱/寒潮两类灾害因子并标注受影响季次（图 11/12），比泛谈风险有说服力；⑤ 以经济学语言解释结果（替代性+供需关系使买方转向低价品→问题三利润下降）。
- **格式观察**：45 页，正文至约 p.25，附录 26–45（附录 1–15 为 MATLAB 代码与结果文件）；参考文献 8 条，**约半数仅为网页/公众号/163 新闻链接且无规范著录**；题面口径上重述写"耕地 1213 亩、6 类"，与其余论文及题面常见口径（露天 1201 亩 34 地块 + 大棚另计）不一致，写作时应统一附件口径。
- **可借鉴点**：① 独立数据处理章+数据补全策略；② 遗传算法工程细节（早熟判断、可行性验证流程、进化曲线收敛判断）写得可复现；③ 基准情景下界估算做结果合理性自检，是成本极低的加分动作。
- **不要学点**：① 参考文献近半是新闻/公众号 URL，规范性与可核查性差，答辩易被追问；② 利润波动指标算完只给折线图（图 16）不给数值表，"选出方案 3 号"缺可复核中间量；③ 模型评价 7.3 段出现乱句、摘要关键词疑似错字，正文中"每种作物种植面积不小于种植地的一半"等假设若与题目"不宜太小"的原意有出入需澄清——交稿前应对齐官方模板做逐页校对。
