# 素材登记表模板

> **每产出一个素材立即登记**，不要等到写论文或收尾时回溯。
> 目的：保证论文里每一张图、每一个数字都能回答"**从哪来、由谁生成、什么粒度**"。

|---|---|---|---|---|---|---|---|
| 1 | | 图/表/数字 | | | | | |

---

## 登记要点

1. **数据粒度必须写清**：图若需要逐时段序列，而结果文件只存聚合量，
   必须注明"由绘图程序自行重算细粒度"，避免用聚合量反推导致曲线失真；
2. **生成程序必须可复现**：交付前确认每个素材都能由交付包内的程序生成；
3. **正文引用位置**：写清在哪一章哪一节使用，便于改动时定位；
4. **交付前核对**：逐条检查"论文里的每个图/表是否都在本表内"。
