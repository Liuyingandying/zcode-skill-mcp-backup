# LaTeX 工作流模板

> **适用范围**：**选用 LaTeX 排版时**参考本文件；其它排版工具的对应做法见
> `references/tool_and_env_guide.md` §3.2 与 §3.3（通用要求与工具无关）。
>
> 目标：让**写作与修改高效、可验证**，且**每次改动都能立刻看到效果**。

---

## 一、工程结构

```
论文工程/
  main.tex            主文件（preamble + \input{body}）
  preamble.tex        导言区（字体、页面、宏包、自定义环境）
  body.tex            正文骨架（摘要页 + 章节顺序 + 参考文献 + 附录）
  sections/           每章一个文件（sec1_xxx.tex …）
  figures/            图片
  refs.bib            引用库
  build 脚本          一键编译脚本（按平台取 .sh / .ps1 / .bat）
```

**好处**：章节独立成文件 → 可**单章预览**、可并行编辑、diff 干净。

## 二、核心技巧

### 2.1 单章实时预览
为每章生成一个预览驱动文件：

```latex
% preview_secN.tex
\def\mmcpreviewtrue{}
\input{preamble}
\includeonly{sections/secN_xxx}
\begin{document}
\input{body}
\end{document}
```

编译该驱动只输出这一章 → **改一章只看一章**，迭代极快。

### 2.2 预览与全文的引用编号一致
预览只引用本章文献时，引用编号会与全文不同。解决办法是在预览模式下
**直接指向全文已生成的引用库**：

```latex
\ifmmcpreview
  \def\bibliography#1{\input{main.bbl}}
\fi
```

这样预览里的角标与全文完全一致。

### 2.3 一键编译
编译脚本依次执行：**多次主编译 → 引用工具 → 再编译**，确保交叉引用与目录收敛。
（交叉引用未收敛时，页数与引用会漂移，必须以最后一次为准。）

## 三、编译指标卡（**交付硬指标**）

每次编译后记录并与目标比对：**页数落在模板规定范围内，其余四项全部为 0**，才算通过：

| 指标 | 目标 | 说明 |
|---|---|---|
| 页数 | 正文与附录分别在模板规定范围内 | 记录分章页数便于控篇幅 |
| 错误 | **0** | 编译中断级错误 |
| 未定义引用 | **0** | 含跨文件搬移后的失配 |
| 溢出行宽（Overfull \hbox） | **0** | 表格/公式超宽的主要表征 |
| 缺字（Missing character） | **0** | 字体未覆盖的字符 |

```markdown
## 编译指标
页数：总 __ ｜ 正文 __ ｜ 附录 __
错误 __ ｜ 未定义引用 __ ｜ 溢出行宽 __ ｜ 缺字 __
```

## 四、常见问题的处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 满篇"未定义引用" | 交叉引用未收敛 | 再编译一次；仍有则检查标签是否被删 |
| 引用指向别处 | **同名标签被定义两次** | 全库搜标签名，去重（结构性搬移后必查） |
| 表格/公式超宽 | 列宽或不可断行 | 用可断列的列格式；避免不可断行的长串数字 |
| 中文缺字 | 字体未覆盖 | 换字体或替换字符（如把特殊序号改为普通括号数字） |
| 中文路径下渲染失败 | 渲染工具不支持非 ASCII 路径 | 先渲染到临时目录再拷回 |
| 图内中文变方框 | 绘图时字体未落地 | 显式指定**本机存在**的中文字体并验证 |

## 五、图表的写法约定

- **图内不写标题**，标题一律交给图注（便于统一字号与编号）；
- 浮动体位置参数与正文段落绑定，避免图文漂移；
- 表格与图**各有唯一标签**，正文用引用（不写死编号）；
- **每个图表都登记来源**（见 `templates/material_registry_template.md`）。

---

## 六、与写作契约的配合

契约中可脚本化的条目应做成检查项（禁用词、字号一致性、汇总行格式等），
**在编译脚本末尾自动执行**，把"人工复读"与"机器检查"分开：

- **机器查**：禁用词、格式一致性、引用完整性、编译指标；
- **人工查**：语病、口语、逻辑、题注与内容是否相符（见论文手"成稿复读"）。
