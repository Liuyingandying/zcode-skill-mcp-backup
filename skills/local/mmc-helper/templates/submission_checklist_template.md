# 提交前 Checklist（Phase 3）

> 填法说明：收尾时逐项核对，**全部 Yes 才可提交**；未过项需解决，或经用户明确接受。结合竞赛 Profile 增减项。
> 带 LaTeX 记号的条目（`\cite{}`、`hidelinks`、`Overfull \hbox` 等）**以 LaTeX 为例**；改用 Word 等工具时按同等原则核对（见 `references/tool_and_env_guide.md` §3.2）。

## 一、内容完整
- [ ] 标题、摘要、关键词完整（摘要数值均来自正文）
- [ ] 模型与算法完备（假设 / 方法 / 求解 / 参数定义清晰）
- [ ] 模型假设前后一致，无自相矛盾
- [ ] 题目每一小问都有对应回答（不遗漏）
- [ ] 结论明确回答了题目的要求

## 二、数据与证据
- [ ] 无"未引用就使用"的结论/数据
- [ ] 图与数据对应（图号/坐标轴/单位/图例正确）
- [ ] 敏感性 / 稳健性分析已覆盖相关小问
- [ ] **无"把推断写成实测"**（证据分级：VERIFIED/INFERRED 标注到位）

## 三、引用与文献
- [ ] **引用真实性复核已通过**（无幻觉、每条可验证标识）
- [ ] 正文 `\cite{}` ↔ `.bib` **一一对应**（无多余 / 无缺失）
- [ ] 参考文献格式符合赛题/Profile 要求

## 四、合规与声明
- [ ] **AI 使用声明**已按竞赛条款定详略，措辞"如实 + 突出人类核心"（已问宽/紧凑）
- [ ] 未抄袭、无侵犯；附录引用规范
- [ ] 数据来源声明（若赛题要求）

## 五、格式与交付
- [ ] 字数、页数、排版符合赛题/Profile 要求
- [ ] 附录（代码/数据/中间推导）排版规范
- [ ] 提交格式正确（PDF/Word，命名符合）
- [ ] **格式符合赛题/用户模板**（页边距/字体/字号/行距/页码/图标题单位）——见 `references/format_presets.md`
- [ ] **结构层级对齐官方模板**（问题X 嵌在"模型的建立与求解"下，其下建立/求解/结果分析；无自造顶层节）
- [ ] **摘要页版式**（题目居中大号粗体、"摘要"居中、正文小字号；无"本文亮点"等非标准内容）
- [ ] **表格合规**（一律三线表单对行；符号说明不一行两排；固定列宽收敛页宽）
- [ ] **题注/小标题合规**（题注=一行主标题+补充另起行；小标题必要且有实结果；结果分析直接承接图表）
- [ ] **无花哨排版**（无彩色填充框 / `\boxed` / 彩色 hyperref 链接；`hidelinks`）
- [ ] **编译无 `Overfull \hbox` / 缺字符 / 未定义引用**
- [ ] **渲染抽查关键页已做**（摘要页、图表页、表格页：无超行宽、无表格撑破页宽、无缺字）——详见 `templates/paper_format_rules.md` §8
- [ ] **工程包已整理**（`00~06` 目录 + `_mmc_internal` 已归纳，可提交）
