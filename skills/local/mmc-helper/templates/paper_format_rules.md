# 论文格式与版式规则（写作前必读 · 边写边遵守）

> 用途：这是论文手**动笔之前必须读完的"格式准备模板"**。所有规则要在**写稿时就遵守**，不能让排版问题拖到收尾才修（能编译 ≠ 排版合格）。
> 适用：每个小问开写前通读一次；Phase 3 组装全文前再通读一次并按 §8 做渲染终检。
> 优先级：**赛题官方模板 / 注意事项原文 > 用户提供的优秀论文模板 > 本规则默认**。规则由多次竞赛的写作复盘归纳而成，可视为"常见扣分点"的排版清单。
> **适用范围**：结构、版式与图表的**通用要求**与排版工具无关；文中涉及 `\paragraph{}`、`main.log`、`Overfull \hbox` 等**具体写法与检查命令以 LaTeX 为例**，改用 Word 等工具时按同样的原则执行（见 `references/tool_and_env_guide.md` §3.2–§3.3）。
> 关联：`templates/paper_writing_guide.md`（写作思路导引·主件）、`paper_skeleton_template.tex`（对齐模板的 LaTeX 骨架）、`references/paper_structure_reference.md`（优秀结构）、`references/format_presets.md`（格式预设）。

---

## 1. 结构：写作前先对齐赛题模板层级（最容易扣分）

1. **先读官方模板**（官方的论文模板文件 / 赛题通知），按它的标题层级定正文骨架，**不要按自己的习惯分章、不要把每个小问做成顶层节**。
2. 国赛常见层级（以官方模板为准，写法示例见 `paper_skeleton_template.tex`）：

   ```
   摘要 → 问题重述 → 问题分析（问题X分析）→ 模型假设 → 符号说明（与假设分节）
   → 模型的建立与求解（问题X：其下再分"模型的建立 / 模型的求解 / 结果分析"）
   → 模型的分析与检验 → 模型的评价·改进·推广（优点/缺点/改进/推广）
   → 参考文献 → 附录
   ```

3. 同一节内步骤太多时**不堆同级小标题**：细节用不编号的段落（LaTeX 中为 `\paragraph{}`）或段落内粗体引导；小标题只留给"模型的建立 / 模型的求解 / 结果分析"这类必要结构。
4. **小标题下必须有实内容/实结果**，不能只有引导句就结束（防"看着像漏写"）。

## 2. 摘要页版式

1. 题目**居中**、大号粗体（如二号）；"摘 要"居中；摘要正文小字号（如五号）、紧凑（一般一页内）。
2. 摘要内容只留：开头总述 + 逐问（做了什么/方法/结果）+ 关键词。
3. **删"本文亮点""创新点""特色"等非标准小节/套话**，不写入摘要。
4. 摘要里每个数值都必须来自正文（最终写，写完与正文核对）。

## 3. 图表规范

1. 图/表编号连续；**题注精简 = 一行主标题**；"左/右、坐标轴含义、读法、数据来源"等**补充说明另起一行**（小字号），不要全部塞进题注。
2. 结构图/流程图/框图：**白底 + 深色线框、简洁灰度**，不用彩色填充框（红/绿/蓝）。复杂图请用户协助绘制。
3. 链接**用 `hidelinks`**（hyperref），去掉 `\boxed{}` 与彩色链接框。
4. 每个图/表正文都要有一句解读；结果分析**直接承接图表陈述数据与结论**，不单开"结果解读"等冗余小标题。

## 4. 表格规范

1. **一律三线表**（booktabs：`\toprule`/`\midrule`/`\bottomrule`），**无竖线**。
2. "符号说明"等符号对照表**每行一对**（符号 | 含义），**不要一行放两排**。
3. 内容多 → 精简列/行，用**固定列宽 + 小字**收敛到页宽以内；**宁可拆成两张表，不撑破页宽**。

## 5. 公式规范

1. 公式里每个符号都要在正文/符号表交代含义。
2. **长公式 / 多 `cases` 不排一行**（会超行宽）：用 `align`/`aligned`/`array` **分行堆叠**；必要时 `\small`；极端才 `\resizebox`。
3. **行内不放"无断点超长串"**（如 `[0.032,0.077]/[0.073,0.135]`、`0.05/0.10/0.20`、长 URL、大分式）——无断点就会溢出；改成**表格**或**分号分行**表达。

## 6. 去花哨

不用彩色填充框、`\boxed{}`、彩色 hyperref 链接框（用 `hidelinks`）；图表配色克制、学术灰调。

## 7. 每节写完的版式自检（写稿即跑，不等收尾）

> 每写完一个小问的正文/一节，先过一遍再写下一节：

- [ ] 结构层级符合 §1 的模板骨架（未自造顶层节、未把细节堆成同级小标题）
- [ ] 新放的小标题下有实结果
- [ ] 新增图表：三线表？题注=一行主标题（补充另起一行）？正文紧跟一句解读？
- [ ] 无彩色填充框 / `\boxed` / 彩色链接
- [ ] 长公式已分行；无行内无断点超长串
- [ ] 表格列宽收敛页宽内（固定列宽+小字已用，或已拆表）
- [ ] 摘要/结论里的数值与正文一致

## 8. 收尾渲染终检（Phase 3 · 收尾助手执行）

1. **编译后扫 `main.log`**：`Overfull \hbox`（内容超宽）、缺字符/缺字体、未定义引用（`undefined references`）、未定义控制序列。
2. **渲染抽查关键页**（把 PDF 转图或打开逐页看）：摘要页、每个图表页、每个表格页——检查超行宽、表格撑破页宽、题注折行难看、图片溢出页边。
3. **结构与内容抽查**：层级对齐模板（§1）、摘要页版式（§2）、小标题无空节（§1 第 4 条）。
4. 数值抽查：图上数值与正文/结果摘要一致；摘要数值来自正文。
5. 全部通过后才进入"格式符合模板 + 无 Overfull"的提交核对（`templates/submission_checklist_template.md`）。
