# 摘要模板（Phase 3）

> 填法说明：摘要通常**最后写**，是评审最先看、最影响第一印象的部分。中文 300~400 字左右；美赛需英文。**每句话都要有依据**，不夸大、不引入正文没有的结论。
> **摘要页版式（写作时即遵守，规则见 `templates/paper_format_rules.md` §2）**：题目**居中**大号粗体（如二号）、"摘 要"居中、正文**小字号**（如五号）紧凑（一般一页内）；只留"开头总述 + 逐问（做了什么/方法/结果）+ 关键词"，**不写"本文亮点/创新点"等非标准内容**。

## 结构（四段式，每段一句话或两句）
1. **背景/问题（一句）**：针对什么背景、题目要解决什么问题。
2. **做了什么（二到三句）**：核心建模思路、关键模型/算法、求解流程。
3. **主要结果（一至三句）**：关键数值/结论，突出亮点（精度、稳健性、可解释性）。
4. **结论/评价（一句）**：模型有效性、稳健性、适用性/可推广性。

## 中文摘要
```
针对[背景]问题，本文建立了[模型/方法]。[做了什么，如先……再……用……]。求解得到[关键结果]。结果表明[结论]。模型[优点/稳健性/适用性]。
关键词：[关键词1]；[关键词2]；[关键词3]；[关键词4]；[关键词5]
```

## 英文摘要（美赛用）
```
This paper proposes ... for [problem]. We first ..., then ..., and apply ... . The results show that ... . The model is [robust/interpretable/applicable].
Keywords: [keyword1]; [keyword2]; [keyword3]; [keyword4]; [keyword5]
```

## 自检（写完后必过）
- [ ] 摘要引用的结果/数值都来自正文（无非正文内容）
- [ ] 没用"我们证明了 X"除非确实证明；推断用限定语（证据分级）
- [ ] 摘要能独立看懂，不必看正文
- [ ] 关键词 3-5 个，覆盖问题/方法/结果
- [ ] 字数符合赛题要求
- [ ] **摘要页版式**：题目居中（大号粗体）、"摘要"居中、正文小字号紧凑一页内；无"本文亮点"等非标准小节（`templates/paper_format_rules.md` §2）
