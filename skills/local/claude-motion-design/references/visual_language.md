# visual_language.md — 总视觉语言

> 源头：Claude Opus 5.5 官方宣传片逆向（SHOT_ANALYSIS.md，22 项帧级验证），
> 经两个工程（opus55-video-lab / motion-lab）实践校准。

## 一句话

**静字活景**：文字层绝对静止，生命感全部来自背景层；高级感 = 极低信息密度 × 极高质量密度。

## 四根支柱

1. **动静分层**——每帧只有一个"活"的东西：照片在缓推、纹理在漂移、颗粒在沸动，而衬线字钉死在画面上。参考片全场没有一个字的位移。
2. **硬切即节奏**——无叠化无滑屏。剪切点就是节拍器，加速剪切 = 音乐渐强的视觉等价物。留白（无文字段）是语法的一部分，不是浪费。
3. **地平线构图族**——全部镜头归属"暗空 + 发光轮廓线 + 质感主体"一族：行星晨昏线、织物边界、纸张曲线。文字基线落在轮廓线上方（画面 30–47% 带区），像立于地平线的日出。
4. **先抑后扬收束**——产品卡静场（音乐骤降）→ 品牌字 + 辉光/黎明升起。开头是"一条地平线亮起"，结尾是"黎明升起"，首尾呼应。

## 色彩叙事模式

暗琥珀（孕育）→ 全谱纹理对拍（多样性：teal/blueprint/cream 各一拍）→ 近黑静场（沉静）→ 暖橙黎明（希望）。品牌主色只出现在收束与点睛，不污染蒙太奇。

## 禁止

- 每帧多个信息主体（大字+子标题+按钮同屏）
- 元素逐个入场（bullet 逐条飞入 = PPT）
- 边框卡片、圆角面板、阴影堆叠
- 元素滑入/滑出（位移是禁手；只有 scale 1.02→1.00 弹入）
- 持续 zoom（参考片铁律：慢速分数缩放会让小字漂移；只允许镜头级缓推）
