# visual_metaphor.md — 视觉因果链（画面承担论证）

> 来源：TJU_intro_10s_v3 复盘。narration 轨道已验证（文字结构正确），
> 但抽象纹理（黎明/墨球/绿叶）与主题"一所现代大学诞生"**没有因果关系**——
> 观众关掉字幕看到的是"一些好看的抽象画面"。本文档确立画面层的第一性原则。

## 一、核心原则

**文字不是解释画面；画面必须承担论证。**

检验法（"关字幕测试"）：关闭字幕后，观众能否仅从画面序列推断出"一个现代大学
正在被建立"？如果能——画面在论证；如果只看到"抽象美感+偶尔的年份"——画面
在装饰，字幕在替画面干活。

抽象纹理的地位：允许作为**转场呼吸与情绪衬底**（1–1.5s，不承担信息），
但**不得承担叙事节拍**。叙事节拍必须由档案物证承担。

## 二、视觉因果链（Visual Causal Chain）

一镜的"意义"= 它为下一镜提供的**问题或证据**。镜头排序必须是可推理的因果：

```
时代氛围（旧世界） → 人（决定者） → 文书（决定被记录） → 物（制度落成）
     ↑因                ↑意志             ↑证据              ↑结果
```

每一镜回答一个观众心中的隐含问题：
1. "这是什么时代？" → 光线/纸张/旧物
2. "谁在做这件事？" → 一个具体的人
3. "这件事被确认了吗？" → 官方文书（红印）
4. "它变成了什么？" → 建筑矗立 / 名字落下

## 三、档案素材的镜头语法（assets/tju-history 实证）

| 因果角色 | 素材 | 镜头语法 |
|---|---|---|
| 时代氛围 | peiyang-1900（旧校景）、纸纹 | 极缓推 + 暗角 + sepia 重颗粒，画面边缘发虚 |
| 决定者 | sheng-xuanhuai-portrait | **向上摇至面部（等效缓推至脸）**，停留 1.5s——人物出场必须有"注视"时长 |
| 决定文书 | first-diploma / xiqian-order | **红印特写起手**（ Seal = 权力在场），再拉开至全文 document focus |
| 制度落成 | peiyang-main-1903 建筑照 | 底部起势的缓推（建筑"生长"感）+ 名字压顶 |
| 名称确认 | 校名卡 | 论证终点：前面四镜的答案 |

## 四、三禁与一替代

- 禁抽象天空/山丘承担叙事（v3 的 ink-planet/cream-leaf 即此问题）；
- 禁无意义粒子（装饰只许 FilmGrain 颗粒——胶片物理性，非"粒子特效"）；
- 禁 AI 生成历史画面；
- 替代：所有"氛围"需求用**真实档案的局部**解决（纸张纤维、印泥红、建筑剪影）。

## 五、节拍设计规则

- 每镜 ≤5s；因果链每环 1–2 镜；
- 年份/名字等**确认性文字只在物证出现后落下**（先证据后结论）；
- 相邻镜头之间允许"继承运动"（同一推近方向延续）以保持因果的连续感；
- 剪切加速保留（v3 验证有效），但**加速发生在证据链内部**，不在证据之间。
