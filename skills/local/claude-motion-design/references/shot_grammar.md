# shot_grammar.md — 镜头语法

## 五幕结构（60–120s 品牌片的骨架）

| 幕 | 占比 | 内容 | 节奏 |
|---|---|---|---|
| A 开场 | 5–8% | 单纹理长镜（dawn-limb 类），**无文字** | 慢推 1.00→1.05 |
| B 铺垫蒙太奇 | 15–20% | 2 长镜 + 加速短切 | 2.1s → 1.5s → 0.4s |
| C 文字蒙太奇 | 30–40% | 衬线词/句跨切持续，背景连切 | 稳定 0.3–0.6s/切 |
| D 转折/里程碑 | 15% | 年卡大字或关键档案照，音乐骤降对齐 | 1.2–2s 静置 |
| E 收束 | 12–15% | 品牌锁定卡 + 辉光/黎明升起 + 淡黑 | 3.5–4.5s |

20s 短片压缩版：A 1.2s → B 2.1s → 年卡 2s → 照片段 ×3（各 3s）→ 转折纹理 1.8s → 收束 3.7s。

## 场景四型（引擎已实现）

| kind | 用途 | 关键字段 | 视觉行为 |
|---|---|---|---|
| `texture` | 开场/过渡/无图段落 | texture id, text.lines | 纹理 + 缓推 + 衬线行弹入 |
| `photo` | 历史/产品照片 | photo, archival, title, caption, year | 单照双层视差（模糊远景反漂 + 锐利层缓推）+ 可读性暗带 |
| `yearCard` | 年份里程碑 | texture, year, title | 大年份(34%) + 名(50%) + 标语(68%) 三级落下 |
| `endcard` | 品牌收束 | title/sub/motto/yearRange | 近黑 + 底部辉光呼吸 + 品牌字，可选淡黑 |

## 剪切规则

- 相邻场景 `start = 上一场景 end`（硬切），引擎不留缝、不叠化；
- 文字跨切持续：`text.lines` 从 `enterAt` 起常驻到场景结束，**跨场景不延续**（每景重落）；
- 文字段换词 = 前词 4f 退出 + 后词 6f 弹入，任意时刻至多一个文字主体；
- 每 3–5 秒必须有一次变化：剪切 / 文字落点 / 机位推进幅度变化，三者任一。

## 音乐对位（可选）

`audio.volumeCurve = {base, dropAt, dropTo, fadeOutFrom}`：常规音量 → 里程碑卡帧处骤降 → 静场 → 淡出。
选曲标准：前 8s 安静（RMS<0.08）、中段渐强、自带 drop 优先。

## 校验清单

- [ ] 开场有无文字前长镜（≥1.2s）？
- [ ] 最短镜头是否 ≥0.4s？（参考片最短 0.24s，新手建议 ≥0.4s）
- [ ] 里程碑卡是否对齐音乐 drop？
- [ ] 结束帧是否落在品牌字完整可见 + 辉光呼吸态？
