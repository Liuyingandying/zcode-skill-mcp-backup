# storytelling_grammar.md — 发布片叙事语法（Claude / Apple 类）

> 来源：TJU_history_90s_v2 复盘。该版本逐项符合视觉规范（衬线/缓推/硬切/留白），
> 但观感仍是动态 PPT。本文档记录失败根因与修正原则——**视觉规范合规 ≠ 叙事成立**。

## 一、根因诊断：展签 vs 叙事

v2 的 25 个场景在结构上是同一种东西的重复：

```
[一张图] + [一个标签] → 硬切 → [另一张图] + [另一个标签] → …
```

"北洋大学堂" + 建筑照片：图和字说**同一件事**——这是博物馆展签，不是电影。
PPT 的本质不是"难看的动画"，而是**信息以并列方式罗列、互不积累**。v2 每个场景
引入一个新话题然后丢掉它，观众每 3.5 秒被要求重新开始一次注意。

对照 Claude Opus 5.5 参考片：全片只说**一句话**——"There's more to discover"。
句子分三段、跨 6 个以上镜头组装；画面是互不相干的抽象纹理（墨、绸、纸、金属），
**没有一个镜头在图解文字**。文字负责意义，画面负责情绪——两轨分工，互不冗余。

## 二、五条叙事原则

### 1. 文字是叙述，不是标签
文字必须构成**对观众说的话**（一个主张/邀请/判断），而不是描述画面内容的名词。
检验法：遮住画面，只读字幕——如果能连成一段话，是叙事；如果是一串词条，是展签。

### 2. 双层独立节奏
- **画面层**：快速剪切（0.4–3s/镜），提供能量与质感变化；
- **文字层**：慢速节拍（1.2–2.5s/短语），**跨剪切持续**——文字的寿命独立于任何单个镜头。
两层节奏不同才产生电影感；1:1 锁死（一镜一标签）即 PPT。
引擎落实：`narration[]` 顶层数组，enterAt/exitAt 以全片时间为坐标，与场景边界无关。

### 3. 时间性积累（Temporal Accumulation）
句子分短语先后出现，**后一个短语替换前一个**（参考片：There's → more to →
discover，同屏始终只有一段），完整句在观众脑中组装。空间上不堆叠，时间上不重复。

### 4. 论证先行，名字殿后
产品名/校名是论证的**结论**，永远最后落地。先建立张力（时间/命题/悬念），
名字落下时是"答案揭晓"，而非开场自我介绍。Apple：先" crazy "后 iPhone；
Claude：先"discover"后品牌卡。

### 5. 质感非图解
画面提供情绪与质感（纹理/光/物质），**不提供字面说明**。文字说"救国"，
画面就不该出现"救国的照片"——该出现的是黎明、纸张、墨。图与字说得越不是
一件事，片子越高级；说得越一致，越像新闻配图。

## 三、节奏原则

- 开场留白 ≥3s（第一拍永远无文字）；
- 短语节拍 1.2–2.5s，逐拍**加速后收稳**（参考片：2.0s → 2.0s → 2.4s 收）；
- 每短语恰好覆盖 1–2 个剪切，剪切点落在短语更替处；
- 全片文字总量 ≤ 30 字（90s 片）；10s 片 ≤ 14 字。

## 四、10 秒开场节拍表（本语法的最小完整实现）

| 帧区间 | 画面层（硬切加速） | 文字层（跨切持续） |
|---|---|---|
| 0–105 (3.5s) | dawn 黎明，纯留白 | — |
| 105–180 (2.5s) | ink-planet 黑白墨球 | **1895**（230px，105–135 在前镜已现，跨切持续至 132 退） |
| 180–232 (1.7s) | cream-leaf 纸上叶（转亮） | **一所大学**（186 入，跨 232 切持续） |
| 232–270 (1.3s) | paper-print 档案纸 | **因救国而生**（200 入——跨 232 切持续；262–266 退） |
| 270–300 (1.0s) | paper-print 同场持续 | **北洋大学堂**（272 入，结论落地，不退） |

论证链：时间（1895）→ 主语（一所大学）→ 使命（因救国而生）→ **名字（北洋大学堂）**。
校名作为论证结论在最后一拍落下——这是"发布"，不是"介绍"。
