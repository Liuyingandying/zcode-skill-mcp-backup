# companion_grammar.md — AI Companion 类产品叙事规则

> 适用于：AI 伙伴 / 桌宠 / 陪伴型 Agent / 情感化助手的品牌叙事片。
> 与 `product_launch_grammar.md`（功能价值链）互补：launch grammar 回答"它能做什么"，
> companion grammar 回答"它和你如何变得亲密"。关系形成过程 = 产品本身。
> 硬性前提：一颗可贯穿全片的生命信号（光点/脉冲/呼吸态）必须在第 0 帧就存在。

## 五条叙事原则（不可裁剪）

### 1. 孤独状态（Loneliness）
开场必须让观众先感到"空"。
- 用户与 AI 之间存在**距离**：空间距离（画面两极）+ 状态距离（未同步的脉冲节奏）。
- 手法：巨大黑暗系统 + 唯一微弱信号；光点**冷色**、慢脉冲、小尺度；
  背景可以有暗示巨大系统的极暗结构（星尘/网格），但永不点亮。
- 禁：开场出现品牌色、开场出现产品形态、快节奏。

### 2. 第一次连接（First Response）
**AI 不是出现，AI 是回应。**
- 必须由**用户先发出信号**（一个请求/一个问题/一次互动），AI 的第一次状态变化是
  对该信号的**响应**，时序上严格后于用户信号（帧级可验证：用户脉冲帧 < AI 变化帧）。
- 最强表达 = 状态转换：冷→暖（品牌色首现即情绪转折，不再是装饰）、
  慢脉冲→同步脉冲（AI 的节奏开始跟随用户）。
- 禁：AI 主动演示能力、无用户输入的自我展示。

### 3. 共同记忆（Shared Memory）
**Memory 不是数据库，是共同经历。**
- 禁止 Memory 模块/缸体/数据库隐喻。用**时间**表达：Day 1 / Day 30 / Day 365 跳跃。
- 每次交互留下一个节点，节点位置在**两者之间**（经历发生在关系中间，不在任何一方的仓库里）。
- 节点随时间累积并自然连成轨迹；同时**两环距离逐段缩短**（空间=亲密度）。
- 禁：节点流向单一仓库、缸体、文件柜、"REMEMBER"器件标签。

### 4. 成长（Understanding）
**AI 不是完成任务，是逐渐理解用户。**
- 能力展示必须是因果链：用户目标 → AI 理解（可见的聚焦/思考态） → 调用能力 → 结果返回。
- Skills/MCP/Tools 只是**幕后机制**：至多一瞬模糊线束/暗流示意，不命名、不展开、不列表。
- 结果落回用户环并使其变暖——能力的意义由"用户的感受"呈现，不由功能枚举呈现。
- 禁：芯片网格、总线图、模块清单、进度面板等架构图语法。

### 5. 陪伴（Together）
**最终不是"AI 存在"，而是"双方连接"。**
- Avatar 必须由**前面留下的全部记忆节点凝聚**而成——它是时间的结果，不是加载的资源。
- 结尾构图 = **两个连接的系统**（用户环 ↔ AI），连接线双向流动（往返光珠交替），
  记忆节点环绕在外——孤点开场与双系统结尾构成闭环。
- 结尾文字禁普通 slogan（"XX，让生活更美好"类），用关系动词：
  "Growing with you." / "与你共同成长"。

## 通用执行规则

- **镜头必须承担论证**：每幕有 1 个可验证的因果拍点（谁先动、谁回应、什么留下了）。
- 旁白 ≤4 句、全部后置于视觉拍点；语气是描述关系（"它回应了/它记得/它懂了"），
  禁展签、禁能力清单、禁形容词堆砌。
- 状态即叙事：光点只有三种状态——孤独（冷/慢）、回应（转暖/同步）、陪伴（成形/对视）。
  全片任何时刻的光点状态必须可归入其中之一。
- 视觉延续：每一幕的产物必须出现在后面的幕里（节点→凝聚成 Avatar→环绕双系统）。
- 复用 primitives：WanderLight（生命信号）、MemoryTrail（经历轨迹）、ExecRing（理解/完成态）、
  Avatar（凝聚成形）、BrandConvergence（结尾）。缺失才新增，新增须回写本文件。
