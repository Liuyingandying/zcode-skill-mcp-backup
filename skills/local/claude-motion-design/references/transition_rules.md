# transition_rules.md — 转场规则

参考片 500 帧逐帧验证结论：**转场只有一种——硬切**。全片无叠化、无滑屏、
无形状转场、无闪白。任何"加料"转场都会立刻暴露模板感。

## 三种合法转场（SceneTransition.tsx）

| 转场 | 何时用 | 参数 |
|---|---|---|
| **硬切**（默认） | 蒙太奇段落一切换 | 相邻场景 `start = 上一场景 end`，零重叠 |
| **Crossfade**（≤18f） | 仅幕间：蒙太奇→收束卡、章节转换 | `Crossfade fadeIn/fadeOut` |
| **FadeToBlack**（≥1s） | 仅片尾最后一拍 | `FadeToBlack startBeforeEnd=18` |

## 硬切的质量要求

切点前后两帧必须**构图同族**（地平线族内切换），亮度差 ≤2 档——
参考片的切点之所以"干净"，是因为所有镜头共享同一构图语法。
新纹理/新照片入片前先目检：切进来的第一帧是否有清晰的轮廓线与暗部承接。

## 文字的"转场"

文字不转场——**旧词 4f 退出、新词 6f 弹入**，且换词点对齐剪切点（±3f）。
任意时刻至多一个文字主体。文字跨切持续时（同场景内背景连切），文字保持零位移。

## 与声音的对位

若有 BGM：剪切点向最近的音乐 onset 靠拢（±3f 内）；里程碑卡的骤降
（volumeCurve.dropAt）必须与年卡/收束卡第一帧同帧。

## 禁止清单

叠化铺满全片 / 滑屏 / 翻页 / 光斑擦拭 / 缩放模糊转场 / 闪白 / 粒子聚合转场。
（这些是"普通宣传片"的第一识别特征。）
