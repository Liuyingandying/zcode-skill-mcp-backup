用 .md 写一个数据说明书 + EDA 摘要，包含：
1. 数据字典：每个字段的【名称 / 含义 / 单位 / 类型 / 取值范围】
2. 样本预览：每个表前 5~10 行（展示结构用）
3. 数据质量：
   - 总行数、列数
   - 缺失值统计（每列缺失数 + 缺失率）
   - 异常值提示（如负数、明显离群值、超出物理范围的值）
   - 重复行数
4. 数值分布（每列）：min / max / mean / std / 25% / 50% / 75% 分位数
5. 类别字段统计：频数分布
6. 相关性：核心变量之间的相关系数矩或文字文本说明
7. 时间字段：时间范围、粒度、是否有间断
