# 数据图表输出规范（任意赛题通用）

> 适用范围：3coding-visual 技能 Step 4——把计算结果落实为**论文可直接用的数据驱动图表**。
> 图内不写大标题（标题归论文 caption）；不画流程图/架构图/技术路线图（那交给 drawio）。
> 本文配套样式库：`figure_style.py`（存放于仓库根 `math-model-method.md/`，与本文不同目录——用前按 §2 把它所在目录加入 sys.path）；高级复刻模板见文末“模板库”一节。

## 1. 环境（本机已实测就绪）

| 项目 | 状态 |
| --- | --- |
| Python 3.13.14 / matplotlib 3.10 | ✅ |
| 中文字体 微软雅黑·黑体·宋体·楷体·仿宋 | ✅ 全在位 |
| numpy / pandas / scipy / sklearn / statsmodels / openpyxl / xgboost / seaborn 0.13 / networkx 3.6 | ✅ |

- 中文 print 不乱码（推荐一次性全局生效）：`setx PYTHONUTF8 1`，新开终端生效；临时用 `python -X utf8 脚本.py`。
- 配了新字体仍出方块 → 清缓存重建：`Remove-Item -Recurse -Force "$env:USERPROFILE\.matplotlib"`。
- 中西文混排的坑：`font.family` 必须给**具体字体名列表**（如 `['Times New Roman','SimSun']`）才会逐字符回退；写成 `'serif'` 抽象名只取第一个字体、中文必缺字形。此逻辑已封装进 `fs.setup()`，勿自己另设 rcParams 覆盖。
- ⚠️ **中文串里混 `$...$` 数学模式 = 豆腐块**（2026-09-11 实测踩坑）：`ax.set_ylabel("外网电价 / (元·kWh$^{-1}$)")`
  会把**非数学部分的中文**也渲染成方块（同图其它纯中文标签却正常，极易误判成字体没配好）。
  原因：字符串一旦含数学模式，整串走 mathtext 字体机制，回退到不含 CJK 的默认字体。
  **对策：中文标签里的单位一律写纯文本**——写 `元/kWh`，不要写 `元·kWh$^{-1}$`；
  确需上下标时改用 `\mathdefault{}` 包裹或把单位整体放到 caption。
  自查：渲染时若出现 `Font 'default' does not have a glyph for '\uXXXX'` 告警，就是这个问题；
  出图后必须**逐张目检**（本仓库有 `python -X utf8 figure_style.py` 自检底座可参考）。

## 2. 用法（import 这套样式，别再每题复制 rcParams）

```python
import sys, os
sys.path.insert(0, r"<仓库根>/math-model-method.md")     # 把 figure_style.py 所在目录加入路径
import figure_style as fs

fs.setup(style="cn-serif")     # 中文宋体+西文 Times（论文规范）；或 "cn" 黑体风 / "en"
fs.fix_seed(42)

import matplotlib.pyplot as plt
fig, ax = plt.subplots(figsize=fs.figsize_cm(14, 8))     # 厘米给宽高
ax.plot(x, y, color=fs.C[0], marker=fs.MARKERS[0], label="方案A")
ax.fill_between(x, y-sd, y+sd, color=fs.C[0], alpha=0.12) # 误差带
ax.set_xlabel("孕周 / 周"); ax.set_ylabel("浓度 / %"); ax.legend()
fs.save_fig(fig, "p2_达标覆盖率", folder="figures")       # 自动存 .png+.pdf
```

## 3. 硬性规范（论文红线，逐条自查）

- [ ] **双格式导出**：PDF（矢量、文本化）插论文 + PNG(300dpi) 预览。SVG 需要二次编辑时再加。
- [ ] **中文论文就中文坐标轴/图例**；图内**不写大标题**（图题放论文 caption，如“图3-1 …”）。
- [ ] 每个数据点**必有数据来源**：图所用数据、生成脚本名记入 `reports/RESULTS_REPORT.md`，图下不空口说“由本文数据得出”。
- [ ] 同一指标的**颜色/线型全篇一致**（方案A 全篇同一色）；多方案用 `fs.C[0..7]` + 线型/标记区分。
- [ ] **先保证图里数字和正文一致**——作图数据来自脚本中间导出（csv/npz），不许手抄改数。
- [ ] 出图后缩放到论文实际宽度（约 7–15 cm）自查：文字不小、线不糊、图例不挡曲线。

## 4. 图型选择速查（按题型）

| 题型 | 常用图 |
| --- | --- |
| 预测 | 真实-预测值对比、误差分布直方、指标对比条形、训练曲线 |
| 优化 | 收敛曲线、方案成本对比、资源利用率、前后对比、灵敏度曲线 |
| 评价 | 综合得分排序、雷达图、相关矩阵热图、箱线图 |
| 数据理解 | 分布直方/KDE、趋势折线、相关散点、箱线/提琴 |

配色/特殊结构参考 `fs.C`、`fs.CMAP_DIV`（发散，如相关矩阵）、`fs.CMAP_SEQ`（顺序，如覆盖率）。

- 大表要精简到“可读列”再放论文；原始全量放附录或 RESULTS_REPORT。
