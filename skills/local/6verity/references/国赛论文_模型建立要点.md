## 一、不同题型的模型建立要点

### 1 预测类问题

```markdown
1.X 预测模型的建立

1.X.1 数据预处理
    - 缺失值处理
    - 异常值检测
    - 标准化/归一化

1.X.2 特征工程（如需要）
    - 特征选择
    - 特征构造
    - 降维

1.X.3 预测模型
    【模型名称】的基本原理是...本文选用该模型是因为...

    【基础模型公式】

    【针对本题特点的改进】

    【参数设置及依据】

1.X.4 模型评估指标
    - RMSE/MAE/MAPE/R²（回归）
    - Accuracy/Precision/Recall/F1/AUC（分类）
```

### 2 优化类问题

```markdown
2.X 优化模型的建立

2.X.1 问题分析
    【将实际问题抽象为数学优化问题】

2.X.2 决策变量定义
    【明确每个变量代表的实际意义】

2.X.3 目标函数建立
    【最大化/最小化什么？为什么？】

2.X.4 约束条件分析
    【逐条列出约束，并说明实际来源】
    - 等式约束
    - 不等式约束
    - 整数/0-1约束
    - 非负约束

2.X.5 完整模型表述
    【用标准优化形式写出】

    【为什么选这个算法？复杂度如何？】
```


## 二、常见错误与规避

| 错误类型 | 典型案例 | 正确做法 |
|---------|---------|---------|
| **公式空降** | 直接写"根据XX模型："然后堆公式 | 先说明"为什么要用这个模型" |
| **符号混乱** | 同一符号在不同公式中含义不同 | 全文符号表统一，首次定义 |
| **假设缺失** | 线性回归不写误差分布假设 | 明确写出$\varepsilon \sim N(0,\sigma^2)$及依据 |
| **改进无据** | "为了更精确，加入交互项" | "根据5.2节分析，两类效应方向相反，故引入交互项" |
| **算法堆砌** | 列出5种算法但不说明选择依据 | 对比各算法适用性，明确选择理由 |
| **结果前置** | 模型建立部分就出现具体数值 | 数值放在"模型的求解"部分 |

## 三、优秀论文金句摘录（可直接化用）

### 1 模型选择
> "考虑到本题【小样本/高维/非线性/动态】的特点，【方法A】的【优势】恰好弥补【方法B】的【不足】，故本文选用..."

> "【方法】虽然【优点】，但其【假设/前提】在本题中【是否满足】。经检验，【数据特征】，因此【结论】。"

### 2 模型改进
> "上述基础模型隐含了【假设】，但5.X节的分析表明该假设不成立。为此，本文引入【改进项】，将模型扩展为..."

> "若【参数】不显著（$p>0.05$），则改进项可忽略，模型退化为【基础形式】，说明【结论】。"

### 3 合理性说明
> "该模型的合理性在于：（1）...；（2）...；（3）..."

> "从【领域】角度看，【公式/参数】具有明确的物理/化学/经济意义：..."

## 四、附录：完整段落示例

### 示例：带类型交互的线性回归（2022C题问题一）

```markdown
### 5.4.1 模型的建立

问题一第三问要求依据风化点的检测数据预测其风化前的化学成分含量。
由于风化过程导致成分比例变化，直接以风化后数据作为配方依据会引入
系统性偏差。因此，需要建立风化效应的定量修正模型。

**基础模型**：假设风化对成分的影响近似线性，建立单因素线性回归：

$$X_c = \beta_0 + \beta_1 d + \varepsilon$$

其中$X_c$为成分$c$的观测含量（%），$d$为风化程度（0/1/2），$\beta_1$
为风化斜率。该模型隐含"所有玻璃风化效应相同"的假设。

**假设检验**：然而，5.3节的Mann-Whitney U检验表明，铅钡与高钾的
风化效应方向截然相反——铅钡风化后SiO₂流失（-28.02%），高钾风化后
SiO₂相对富集（+25.98%）。若忽略类型差异统一建模，类型效应将被误判
为风化效应，导致预测偏差。

**改进模型**：引入类型示性变量$I_{\text{铅钡}}$及其与风化程度的交互项：

$$X_c = \beta_0 + \beta_1 I_{\text{铅钡}} + \beta_2 d + \beta_3 I_{\text{铅钡}} \cdot d + \varepsilon$$

其中：
- $I_{\text{铅钡}}$：类型示性变量，铅钡玻璃取1，高钾玻璃取0；
- $\beta_2$：高钾玻璃的风化斜率；
- $\beta_2 + \beta_3$：铅钡玻璃的风化斜率；
- $\beta_3$：类型对风化效应的调节量，若$\beta_3$显著不为0，则证实
  类型调节作用存在。

**风化前成分预测**：对于风化程度为$d$的样本，其风化前成分估计为：

$$\hat{X}_{c,\text{前}} = X_{c,\text{观测}} - \hat{\beta}_{\text{type}} \cdot d$$

其中$\hat{\beta}_{\text{type}}$根据玻璃类型取$\hat{\beta}_2$（高钾）或
$\hat{\beta}_2 + \hat{\beta}_3$（铅钡）。

**模型合理性**：
1. 线性假设
2. 分类型处理
3. 可验证性
```
