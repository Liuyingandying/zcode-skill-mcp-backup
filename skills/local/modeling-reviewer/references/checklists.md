# Reviewer 检查清单（v1，源自 run_001 教训）

## 1. 假设清单审查
- [ ] 报告中的显式假设逐条有依据？
- [ ] **隐含假设**挖出来了？高发区：面板数据用首测值代表全过程、样本组间独立、删失机制与检测方案无关、误差高斯零均值
- [ ] 每个假设标注：若不成立，哪个结论受影响、影响方向

## 2. 目标函数来源审查（run_001 F3 的直接防线）
- [ ] 逐问列表：目标函数是**题目给定**还是**自造**？
- [ ] 自造目标函数必须有 sanity check 三件套：
  - 极端案例：输入取极值/边界时，解是否荒谬？
  - 单调性：解释变量沿领域常识方向变化时，解是否朝预期方向动？
  - 常识对照：用题目给的领域陈述（如"高 BMI 晚达标"）反推解的方向
- [ ] 自造的权重/常数（如 0.1t 等待成本）逐一追问来源，无来源者标 HIGH

## 3. 变量关系方向审查（可自动化）
- [ ] 回归/HR 系数符号 vs 领域预期方向表
- [ ] 分组结果沿物理量（BMI/浓度/时间）的单调性
- [ ] 多模型互验：同一关系的不同模型（回归 vs Cox）方向一致？

## 4. 极端情况探针
- [ ] 留一稳定性：剔除小样本组/极端点后结论是否保持
- [ ] 端点行为：网格边界、阈值 q=0/1、σ=0 的退化情形
- [ ] 结论翻转测试：噪声扰动下主结论是否翻转（不只是漂移量）

## 5. 承诺-兑现对账
- [ ] 分析报告承诺的每个检验（显著性/假设检验/收敛性检查）在代码中有实现？
- [ ] 论文中的每个数值声称能在结果文件中找到？（配合 paper-pipeline-fixer 的 provenance 门）

## 6. 与其他 skill 的边界
- 发现 CRITICAL → 建议**回到生成阶段**修复，Reviewer 不代改
- 格式/数值漂移类问题 → 转交 paper-pipeline-fixer 的 check 门
